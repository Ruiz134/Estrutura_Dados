## Meu Projeto de Estrutura de Dados ( ETL )

Este é um exemplo de estrutura para um projeto de dados
 que realiza um processo ETL (Extract, Transform, Load) para processar dados de entrada.

 ## 📚 Documentação

A documentação completa do projeto está disponível em:

👉 [Acessar documentação do projeto](https://ruiz134.github.io/Estrutura_Dados/)


 ### Estrutura do Projeto

 ```text
Estrutura_Dados/
├── app/
│   ├── pipeline/
│   │   ├── extract.py
│   │   ├── transform.py
│   │   └── load.py
```
